# WELCOME Reuse Market

Vite + React + TypeScript + Tailwind CSS site for GitHub Pages.

## GitHub Pages

This project is configured for:

```txt
https://kimeguri.github.io/recycle/
```

After uploading these files to the `kimeguri/recycle` repository, open:

```txt
Settings -> Pages -> Build and deployment -> Source -> GitHub Actions
```

Then check the `Actions` tab and wait for `Deploy to GitHub Pages` to finish.
